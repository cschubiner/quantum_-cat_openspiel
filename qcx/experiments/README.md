# qcx experiments archive

Snapshots of experiment branches whose code was not adopted into the shipped champion
(or would change the champion's engine / iOS view contract). Each subdirectory holds that
branch's full qcx sources plus a README with the result and the exact source commit.
Adopted work (fast engine, PIMC, rollout token 0.6, learned rollout policies g1/g3,
policy-based inference code, gen-4 weights) lives directly in `qcx/`.
See `qcx/RESULTS.md` for all numbers.
